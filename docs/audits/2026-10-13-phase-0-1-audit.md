## 3. Scope and limitations

- This is a code/protocol audit, not yet a full raw-dataset audit. No claim is made here that dataset licenses, every source file, duplicate images, target distributions or patient/image linkage have been independently verified.
- No model performance or clinical validity is assessed by this audit.
- Survey records and records with unknown reference metadata may remain in canonical ingestion for traceability, but must not pass the current quantitative benchmark gate.
- The Fingertip adapter's explicit ROI label remains `fingertip`, which is outside the current quantitative Hb ROI contract. Such records are therefore not quantitative-ready under the current contract; do not relabel them as conjunctiva or nailbed.
- The flash-state mapping handles recognized Android Camera2 numeric states (OFF=0, SINGLE=1, TORCH=2) and a small set of textual equivalents. The source dataset's actual metadata encoding must still be confirmed in the dataset audit.
